# Ghasita Finder 🎵

Discover the top songs of any artist, listen to previews, watch music videos, stream on Spotify, and chat with the built-in Singer AI assistant.

---

## ✨ Features
- 🔍 **Top Songs Discovery**: Search any artist to find their top hits with high-res album artwork and audio preview.
- 📺 **Direct Streaming Links**:
  - Watch official music videos on **YouTube**
  - Search & stream on **Spotify**
  - Listen on **Apple Music**
- 🤖 **Singer AI Chatbot**: Ask questions about any artist, such as:
  - Biography & background ("Who is he?")
  - Date of birth / age ("When was he born?")
  - Top hits & song discography
- 🌌 **Aesthetic UI**: Modern glassmorphism UI with animated starry background.

---

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, FontAwesome
- **Backend**: Python, Flask, Flask-CORS, Requests, BeautifulSoup4

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/abhishek036281-ai/ghasita.git
cd ghasita
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the application
```bash
python app.py
```

### 4. Open in your browser
Navigate to:
```
http://localhost:5000
```
